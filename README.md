# My Exercise Tracker Project

## 1. What this project is about
I am tracking my daily exercise habits to see how my workouts connect with how many calories I burn and what my mindset is before I start.

## 2. My Data Columns
* Date: The day I did the activity.
* Exercise: The type of workout (Cycling, Football, Running, Weightlifting, Swimming, or Rest).
* Calories: The total calories burnt.
* Workout Mindset: How I felt before starting (Lazy, Energised, Relaxed, Motivated, or Determined).
